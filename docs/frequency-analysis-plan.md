# PI 頻域與極點實驗擴充

依使用者要求，沿用既有純靜態網站、原碼 PI 與一階教學模型，直接完成並部署。

## 設計

頻域計算以未飽和、每拍積分的離散模型為準；所有圖共用 Kp、Ki、Ts。負載、限幅及積分凍結影響時域模擬，不改寫線性傳遞函數。用開迴路 L 計相位裕度，以閉迴路 H 的相對 DC 半功率點計頻寬，以閉迴路極點是否在單位圓內判定線性穩定性。

沿用本機 SVG 與 KaTeX，避免新增圖表套件。圖中明確處理零增益、純 P 消去、Nyquist 邊界、沒有交越與不穩定模型。增加 Kp 上限與失穩預設，提供限幅模擬對照未限幅線性階躍的小圖。

## 實作與驗證

- `frequency.js` / `frequency.test.js`：複數頻率響應、交越與頻寬、極點、線性階躍及解析解邊界測試。
- `frequency-view.js` / `frequency.css`：Bode、頻率游標、極點、指標與階躍對照。
- `frequency-guide.js`：L/H、Jury、零增益／純 P 退化情形與原碼推導。
- `lab.js` / `simulation.js`：共用參數、較大 Kp 範圍與失穩情境；維持原有時域操作。
- 更新靜態檢查與維護說明，獨立核對數學、特殊狀態與圖表映射。
- 執行數值測試、來源／公式檢查、桌面及手機操作驗證。
- 提交推送後，等 GitHub Pages 完成，驗證公開網站。
