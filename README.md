## 閉迴路實驗室

可調 Kp、每拍 Ki、控制週期 Ts、負載、輸出限幅、額外控制延遲 0–8 拍與量測低通截止頻率。提供平順追蹤、積分偏強、過載、慢取樣、線性失穩、延遲與低通七組情境。圖表分開顯示實體輸出 y／量測 m、當拍命令 u／延遲致動 ua；可疊加另一種積分策略作對照。

模型為 `dy/dt = (-y + u - d) / 0.25`，以精確零階保持離散化；0.5 s 目標升至 0.6，3 s 加載，5 s 卸載。事件對齊到下一個控制取樣，終點為不晚於 8 s 的最後一拍。改變 Ts 時保留 Ki，因此等效 Ti=Ts/Ki 隨之變化。

階躍超調只計加載前；整定／卸載回復採 ±2% 帶且至少觀察 0.25 s 的帶內尾段。未達成、觀察時間不足、不適用皆個別顯示。首次解除限幅與回到誤差帶分開計算；端點誤差不宣稱為穩態誤差。

## Bode 與極點分析

Kp、Ki、Ts、延遲與低通同步驅動時域模擬及未飽和線性模型的 Bode／極點圖。令前向路徑 A 包含 PI、額外延遲與被控體，量測濾波為 F；開迴路 L=AF 顯示相位裕度與增益交越；實體閉迴路 Hy=A/(1+AF) 顯示相對 DC 的首次半功率（約 −3.0103 dB）頻寬，另畫量測閉迴路 Hm=AF/(1+AF)。頻率只計到 Nyquist，提供對數頻率游標及交越跳轉。

以單位圓判定離散極點；純 P 及零增益將保存的中性積分狀態另外標示。無交越、不穩定、臨界、零響應與頻帶內未達半功率門檻分開處理。對照小圖顯示同一組參數的未限幅線性階躍與原本限幅模擬；發散超過 ±4 倍目標時明確標註停止繪製。Kp 上限擴充到 8，以「線性失穩」情境觀察極點越界。

頻域分析不包含飽和閘門及負載恢復；穩定裕度是此教學線性模型的結果。導讀推導 L/H、特徵式、Jury 不等式與極點／時間關係，並說明 Ki 與 Ts 的耦合。

## 控制延遲與量測低通

控制延遲為限幅後命令的整數拍佇列，初始命令為零，原碼積分閘門仍比較 PI 本身上一拍的限幅。低通放在回授端，採截止頻率預扭曲的雙線性一階模型：`m[n]=p*m[n−1]+c*(y[n]+y[n−1])`。截止頻率限定在 `0 < fc ≤ 0.45/Ts`；改 Ts 超出限制時，介面會調整並提示。可一鍵旁路 D/F，保留其他參數比較。

延遲只改開迴路相位；低通同時改幅值及相位。相位裕度使用連續展開相位，長延遲時可低於 −180°；穩定性以全部特徵根判定，不能只讀裕度正負。最高 11 階特徵式的根以殘差與係數重建共同驗證；數值無法確認時顯示未定。頻寬以三角多項式的導數根分段定位，再用複數響應細化首次下降交點。

導讀 11–15 推導延遲、預扭曲低通、Hy/Hm 與高階特徵式，逐段對照原碼低通係數、狀態更新及排程。原碼採未預扭曲係數；教材明確區分此差異，也不把外部頻率量測或 DC 平滑路徑直接當成原機 CV/CC 的 PI 回授。

另補充追蹤、負載及量測雜訊的傳遞路徑，說明噪聲注入位置與抗混疊限制；此為理論延伸，介面尚未加入雜訊模擬。站內搜尋涵蓋八章及三組實驗室導讀，搜尋結果可直接跳至對應導讀。參數輸入不合法時保留上一組完整結果，修正後才將所有待套用欄位一起重算。
